Using these numbers in PyRx

    

      
PrepareLoad the cleaned protein as the macromolecule and your ligands as usual.

      
Open the Vina WizardSelect the macromolecule and ligands, then go forward to the grid box step.

      
Type the boxEnter the three centre values and the three sizes from this page. Check the units read Å.

      
Check itThe box should sit around the pocket in the PyRx 3D view, like the orange box here. Then run.

    

  


  

    
Grid Box Finder v1.2.0 — runs entirely in your browser; structures are never uploaded anywhere.
    Centre is the centroid of the selected site's heavy atoms; each edge is
    ceil(2 × max|atom − centre| + 2 × margin), so the margin is guaranteed on every face.
    The bounding-box midpoint is also shown, for comparison with AutoDockTools.
    Hydrogens and alternate conformations other than A are ignored; multi-model files use model 1.
